# ゴルフ場スタッフのための規則研修

ゴルフ場で働く人が、お客様に自信をもって規則を説明できるようになるための研修アプリと問題集です。
**全1043問**を、規則の構成に沿った章に「現場対応」「まぎらわしい規則」「用語の定義」「委員会の措置」を加えた**10部24章**で収録しています。

1問ごとに **罰の区分**・なぜそうなるか・**その後の処置**・根拠条文が付き、手続きが空間的な規則には**図解**を添えています。
ビルド不要・依存パッケージなしの静的サイトです。

| ページ | 用途 |
| --- | --- |
| `handbook.html` | **問題集**。全1043問を章別に通読・検索・印刷 |
| `index.html` | **テスト**。テストの型・難易度・章を選んで出題、採点、復習 |
| `print.html` | **印刷用シート**。問題用紙・解答用紙・図解シートをA4で刷る |
| `cards.html` | **カード画像**。1問1枚。スライドや掲示に使う |

### 委員会の措置とローカルルール

**個々のローカルルールの中身は出題しません。**ローカルルールはコースごとに違うので、
「ひな型E-5の罰打は何打か」といった問題を解けても現場では役に立たないからです。
この章で扱うのは、ローカルルールを**作る側**が知っておくことです &mdash;
定める権限は誰にあるか、何を定めてよくて何は定めてはいけないか、どう周知すれば有効になるか、
コースの標示をどう決めるか、競技の条件に何を書いておくか。

### 現場対応(ゴルフ場スタッフ)

規則そのものではなく、コースで実際に判断・応対する場面から出題します。
キャディーができること・できないこと(承認が要るか要らないか)、お客様に聞かれたときに答えてよい情報、
スタート時刻の管理、即時中断、スコアカードの受け取り、ペナルティーエリアの標示、一時的な水の判定など。

### まぎらわしい規則

答えが分かれる対比だけを集めた章です。
自然物と人工物、グリーンの内と外、1クラブレングスと2クラブレングス、
誤球と誤って取り替えた球、ペナルティーエリアとOBの判定の向き、など。

## 図解

手続きが空間的で文章だけでは伝わりにくい規則に10点の図を用意しています。
すべてインラインSVGで、ライト／ダークどちらのテーマでも読めるように線と文字は `currentColor` を継承します。

`コースの5つのエリア` / `罰なしの救済 — 救済エリアの決め方` / `後方線上の救済(2023年から)` /
`ペナルティーエリアの救済 — 黄と赤の違い` / `アンプレヤブルの3つの選択肢` /
`バンカー内のアンプレヤブル — 出るには2打罰` / `目玉の球` / `ドロップの手順とやり直し` /
`ストロークと距離 — 打数の数え方` / `暫定球を打てる場合・打てない場合`

## 紙で配る

`print.html` は配布用の紙面を組みます。範囲(章・難易度・必修・問題数)を選ぶと刷り上がりがそのまま画面に出て、
ブラウザの印刷から紙にもPDFにもできます。

| 出力 | 中身 |
| --- | --- |
| **問題用紙** | 設問と選択肢(ア・イ・ウ・エ)と解答欄。配って書き込んでもらう |
| **解答用紙** | 正解の記号・罰の区分・根拠条文・理由・その後の処置 |
| **図解シート** | 図解10点だけ。掲示や研修資料に |

**選択肢の並びは問題IDから決まります。**何度刷っても同じ並びになるので、問題用紙と解答用紙の記号は必ず一致します。
`choices[0]` を常に正解とするデータ構造のまま紙に刷ると答えが全部「ア」になってしまうため、
IDを種にした mulberry32 で並べ替えています(1043問での分布は ア262 / イ264 / ウ268 / エ249)。

問題用紙の図解は、キャプションの説明文が答えそのものを書いていることがあるため見出しだけに切り詰めます。
それでも図から手順が読める問題はあるので、採点する試験では**図解を省く**を選んでください。

URLに条件を付けると、その紙面を直接開けます。

```
print.html?sheet=quiz&must=1&count=50&cols=2   必修50問・2段組みの問題用紙
print.html?sheet=key&must=1&count=50&cols=2    同じ範囲の解答用紙
print.html?sheet=figs                          図解シート
print.html?sheet=quiz&cats=bunker,green&fig=0  バンカーとグリーンだけ・図解なし
```

## カード画像

`cards.html` は1問を1枚のカードにします。スライドに貼る、掲示する、といった用途向けです。
条件の付け方は印刷用シートと同じで、`?answer=1` を足すと正解と理由が入った版になります。

PNGに書き出すには Node と Playwright が要ります(サイト本体の動作には不要です)。

```
node tools/cards.js                      必修から24枚を cards-out/ へ
node tools/cards.js "must=1&limit=50"    条件を指定
node tools/cards.js "cats=bunker" out/   出力先を変える
```

幅1080px・2倍解像度(2160px)で書き出すので、そのまま印刷にも使えます。

## その他の機能

- **練習ラウンド**(1問ごとに解説)と**テストラウンド**(最後に採点)
- 結果画面にスコアカード、範囲別の正答率、全問の見直し
- 間違えた問題だけを繰り返す復習ラウンド
- 記録を `localStorage` に保存
- キーボード操作 — `1`〜`4` で解答、`Enter` で次へ、`←` `→` で移動
- 問題集は全文検索・罰の区分での絞り込み・解答の表示/非表示の切り替え・印刷用スタイル

合格ラインは正答率70%です。

## 出典と検証状況

- ゴルフ規則 2023年版 規則1〜25 および 定義(全336節・定義123項目)
- オフィシャルガイド(詳説・委員会の措置・ローカルルールひな型)
- 2023ゴルフ規則: 5つの重要な変更 / 追加の詳説(2023年10月5日更新)

問題と解説は上記の原文と照合して作成しています。主要な条文については突き合わせを行い、
**判明した誤りは修正済み**です。ただし全1043問の逐条照合は完了していません。

学習用の教材です。競技での正式な判断は、R&A / USGA および日本ゴルフ協会が発行するゴルフ規則の原文と委員会の裁定によります。

### 問題を追加する

該当する `data/q-*.js` の配列に追記します。

```js
{
  id: 'x99',                 // 一意なID
  must: true,                // 必修テストに入れる(任意)
  cat: 'penaltyarea',        // categories.js の章ID
  rule: '規則17.1d',          // 根拠条文
  level: 2,                  // 難易度 1〜3
  pen: 'one',                // none / one / general / dq / varies / info
  q: '設問',
  choices: ['正解', '誤答1', '誤答2', '誤答3'],   // [0] が常に正解
  why: 'なぜそうなるか',
  next: ['その後の処置を手順で', '…'],
  note: '補足(任意)',
  fig: 'penalty-area'        // figures.js の図ID(任意)
}
```

`choices[0]` を常に正解とし、テスト側で表示順をシャッフルします。問題集では紙の問題集と同じように順を固定します。
