# ゴルフ規則スコアカード

2023年ゴルフ規則のテスト問題アプリ。全78問、4択、1問ごとに根拠となる規則番号と解説が付きます。

`golf-rules-quiz/index.html` をブラウザで開くだけで動きます。ビルド不要、依存パッケージなし。

## 機能

- **練習ラウンド** — 1問ごとに正誤と解説を表示
- **テストラウンド** — 最後にまとめて採点。解答は提出前に変更できる
- 範囲と問題数(10 / 20 / 30 / 50 / すべて)を選んで出題
- 選択肢は毎回シャッフル
- 結果画面にスコアカード、範囲別の正答率、全問の見直し
- 間違えた問題だけを繰り返す復習ラウンド
- ラウンド数・ベスト正答率・出題済みの問題数を `localStorage` に記録
- キーボード操作 — `1`〜`4` で解答、`Enter` で次へ、`←` `→` で移動
- ライト / ダークテーマ、モバイル対応

合格ラインは正答率70%です。

## 出典

- 2023ゴルフ規則: 5つの重要な変更 (R&A / USGA)
- 2023年ゴルフ規則の追加の詳説 (2023年10月5日更新)
- ゴルフ規則 2023年版 規則1〜25

学習用の教材です。競技での正式な判断は、R&A / USGA および日本ゴルフ協会が発行するゴルフ規則の原文と委員会の裁定によります。

## 構成

```
golf-rules-quiz/
├── index.html          画面の構造
├── assets/styles.css   デザイントークンとレイアウト
├── assets/app.js       出題・採点・記録
└── data/questions.js   問題データ(全78問)
```

問題を追加するときは `data/questions.js` の `GOLF_QUIZ_QUESTIONS` に追記します。`choices[0]` を常に正解とし、表示順はアプリ側でシャッフルします。
