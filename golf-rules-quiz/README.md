# ゴルフ規則スコアカード / 問題集

2023年ゴルフ規則の学習教材。**全261問**の4択問題を、規則の構成に沿って**6部20章**に分けて収録しています。
1問ごとに **罰の区分**・なぜそうなるか・**その後の処置**・根拠条文が付き、手続きが空間的な規則には**図解**を添えています。

ビルド不要・依存パッケージなしの静的サイトです。ブラウザで開くだけで動きます。

## テストアプリ (`index.html`)

- **練習ラウンド** — 1問ごとに正誤と、罰の区分・理由・その後の処置・図解を表示
- **テストラウンド** — 最後にまとめて採点。解答は提出前に変更できる
- 部・章を選んで範囲を絞り、10 / 20 / 30 / 50 / 100 / すべて から問題数を選択
- 選択肢は毎回シャッフル
- 結果画面にスコアカード、範囲別の正答率、全問の見直し
- 間違えた問題だけを繰り返す復習ラウンド
- ラウンド数・ベスト正答率・出題済みの問題数を `localStorage` に記録
- キーボード操作 — `1`〜`4` で解答、`Enter` で次へ、`←` `→` で移動

合格ラインは正答率70%です。

## 問題集 (`handbook.html`)

- 全261問を章ごとに通読。目次は現在地に追随する
- 全文検索(問題文・選択肢・解説・規則番号)
- 罰の区分(罰なし / 1打の罰 / 一般の罰 / 失格 / 場合による)で絞り込み
- 「解答と解説を表示」と「隠して問題だけ」の切り替え。隠したまま印刷すれば紙の問題集になる
- 冒頭に **罰の体系**と**救済の型**の早見表
- 印刷用スタイルつき(目次・操作パネルは印刷されない)

## 図解

手続きが空間的で、文章だけでは伝わりにくい規則に10点の図を用意しています。
すべてインラインSVGで、ライト／ダークどちらのテーマでも読めるように線と文字は `currentColor` を継承します。

`コースの5つのエリア` / `罰なしの救済 — 救済エリアの決め方` / `後方線上の救済(2023年から)` /
`ペナルティーエリアの救済 — 黄と赤の違い` / `アンプレヤブルの3つの選択肢` /
`バンカー内のアンプレヤブル — 出るには2打罰` / `目玉の球` / `ドロップの手順とやり直し` /
`ストロークと距離 — 打数の数え方` / `暫定球を打てる場合・打てない場合`

### 検証状況

問題と解説は、上記2つのPDFと2023年版ゴルフ規則の内容に基づいて作成しています。
**規則の原文との逐条照合は行っていません。** 原典(R&A / JGA が公開する規則全文)に当たって
一問ずつ突き合わせた検証は未実施であり、誤りが含まれている可能性があります。

学習用の教材です。競技での正式な判断は、R&A / USGA および日本ゴルフ協会が発行するゴルフ規則の原文と委員会の裁定によります。

### 問題を追加する

該当する `data/q-*.js` の配列に追記します。

```js
{
  id: 'x99',                 // 一意なID
  cat: 'penaltyarea',        // categories.js の章ID
  rule: '規則17.1d',          // 根拠条文
  level: 2,                  // 難易度 1〜3
  pen: 'one',                // none / one / general / dq / varies / info
  q: '設問',
  choices: ['正解', '誤答1', '誤答2', '誤答3'],   // [0] が常に正解
  why: 'なぜそうなるか',
  next: ['その後の処置を手順で', '…'],
  note: '補足(任意)',
  fig: 'penalty-area'        // figures.js の図ID(任意)
}
```

`choices[0]` を常に正解とし、テストアプリ側で表示順をシャッフルします。問題集では紙の問題集と同じように順を固定します。
