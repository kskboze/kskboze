# 関数ボット（日本語版）

やりたいことを **日本語で書くだけ** で、Excel / Google スプレッドシートの数式をつくってくれる小さな Web アプリです。
逆に、意味の分からない数式を貼り付けて **解説してもらう** こともできます。

David Bressler さんの [Formula Bot](https://formulabot.com/) に着想を得て、
**日本の実務（和暦・年度・消費税・全角半角・営業日）に強い日本語版** としてつくり直しました。

---

## 動かしてみる（3ステップ）

### 1. Node.js が入っているか確認する

ターミナル（Windows なら PowerShell）で:

```
node --version
```

`v18.0.0` 以上と表示されれば OK です。
入っていなければ [nodejs.org](https://nodejs.org/ja) から「LTS」版を入れてください。

### 2. APIキーを設定する

このアプリは Claude（AI）に数式を考えてもらうので、APIキーが必要です。

1. [console.anthropic.com](https://console.anthropic.com/) でアカウントを作り、APIキーを発行します
2. `.env.example` を **`.env`** という名前でコピーします
3. `.env` を開いて、`ANTHROPIC_API_KEY=` のうしろに自分のキーを貼り付けます

```
cp .env.example .env
```

> `.env` は `.gitignore` に入れてあるので、GitHub には上がりません。安心してください。

### 3. 起動する

```
node server.js
```

ターミナルに出てきた **http://localhost:3000** をブラウザで開けば完成です。
止めたいときは `Ctrl + C` を押します。

> APIキーがまだ無くても起動はできます。画面のレイアウトと、
> ページ下部の「日本のオフィスでよく使う数式」早見表はそのまま使えます。

## ファイルの地図

はじめて読むときは、この順番だと分かりやすいです。

| ファイル | 役割 |
| --- | --- |
| `public/index.html` | 画面の骨組み。ボタンや入力欄はここ |
| `public/style.css` | 見た目。色は先頭の `:root` にまとめてあります |
| `public/app.js` | ボタンが押されたときの動き。サーバーに質問を送って、答えを表示します |
| `server.js` | サーバー。画面を配り、AI への橋渡しをします |
| `prompt.js` | **このアプリの頭脳。** AI への指示文。日本の実務ルールを教えている場所 |

---

## カスタマイズしてみる

いちばん効果が大きいのは `prompt.js` です。

- `JAPANESE_KNOWLEDGE` に、あなたの会社のルール（請求は切り捨て、締め日は20日 など）を書き足す
- `GENERATE_SYSTEM` の説明の書き方を変えて、口調を調整する

`public/app.js` の下のほうにある `RECIPES` に項目を足せば、早見表も増やせます。

## しくみ（ざっくり）

```
ブラウザ                    server.js                  Claude API
   |                            |                          |
   |-- ①日本語で質問 ---------->|                          |
   |                            |-- ②指示文＋質問 -------->|
   |                            |<- ③数式と解説(JSON) -----|
   |<- ④画面に表示 -------------|                          |
```

APIキーはサーバー側だけが持ちます。ブラウザには渡していないので、
画面のソースを見られてもキーは漏れません。

## つまずいたときは

| 症状 | 対処 |
| --- | --- |
| `APIキーが設定されていません` と出る | `.env` ファイルの名前とキーの綴りを確認してください |
| `EADDRINUSE` と出て起動しない | ポート 3000 が使用中です。`.env` の `PORT` を 3001 などに変更 |
| 数式が自分の表と合わない | セル番地は仮のものです。ご自分の表に合わせて `A1` などを置き換えてください |
| 通信に失敗しましたと出る | `node server.js` を動かしたターミナルを閉じていないか確認してください |
